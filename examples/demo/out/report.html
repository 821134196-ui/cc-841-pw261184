未覆盖风险

预算内无法安排、或根本没有候选测试的义务。这些是随本次发布上线的具体缺口。

✖ 危急 · R1

无可用测试:core/crypto @ web 的架构专用验证 没有任何候选

模块 core/crypto 直接变更,web 平台制品已失效,但没有任何 arch/e2e 测试覆盖 (core/crypto, web)。该模块声明的契约 [crypto.sign, crypto.verify] 可由通用契约测试覆盖,但契约之外的 web 平台专属行为没有任何测试验证——通用测试不能替代架构专用用例。需要补一个覆盖该模块该平台用例的架构/端到端测试。

影响如何传导到这里
  1. core/crypto 变更源
▲ 高 · R2

预算不足:app/shell @ web 的架构专用验证 无法安排

模块 app/shell 受变更传递影响,制品需要app/shell @ web 的架构专用验证;最便宜的候选测试 shell-e2e-web 需 90 分钟,但剩余预算只有 50 分钟。该项验证缺失将随本次发布上线,建议追加预算或单独补跑 shell-e2e-web。
